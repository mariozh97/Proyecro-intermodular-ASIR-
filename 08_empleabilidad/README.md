# Itinerario Personal para la Empleabilidad (ITP)

Este apartado recoge el trabajo realizado en el módulo de Itinerario Personal para la Empleabilidad, donde se ha trabajado la definición del perfil profesional y la creación de un portfolio.

---

## Contenido

* **01_perfil_profesional.md** → Descripción de mi perfil y orientación profesional
* **02_sector_profesional.md** → Análisis del sector IT y perfiles profesionales
* **03_presentacion_proyecto.md** → Presentación del proyecto como si fuera para una empresa
* **04_portfolio.md** → Portfolio con evidencias del proyecto
* **05_perfil_github.md** → Organización del perfil y repositorio en GitHub
* **06_reflexion_personal.md** → Reflexión final sobre el aprendizaje

---

## Objetivo

El objetivo de este módulo es empezar a construir una identidad profesional desde el primer curso, utilizando el proyecto como base para un portfolio real.
