# Proyecto Intermodular ASIR

## Descripción

Este proyecto consiste en el diseño e implementación de una infraestructura IT para una empresa de desarrollo de software. A lo largo del proyecto se han integrado distintos módulos del ciclo, aplicando los conocimientos de forma práctica en un entorno simulado.

---

## Objetivo

Simular un entorno real de empresa donde se diseñe, configure y documente una infraestructura completa, integrando redes, sistemas, bases de datos, documentación, hardware, epleabilidad, lenguajes de marcas y servicios en la nube.

---

## Módulos implicados

| Módulo                 | Descripción                                   |
| ---------------------- | --------------------------------------------- |
| Hardware               | Selección y dimensionamiento de equipos       |
| Redes                  | Diseño de red con VLANs y direccionamiento IP |
| Sistemas operativos    | Configuración de servidores Linux             |
| Bases de datos         | Modelo relacional y uso de MySQL              |
| Lenguajes de marcas    | Documentación en XML                          |
| Computación en la nube | Despliegue en AWS (EC2)                       |
| Empleabilidad          | Perfil profesional y portfolio                |

---

## Tecnologías utilizadas

* Ubuntu Server
* Cisco Packet Tracer
* Apache, DHCP, DNS
* MySQL
* XML, DTD, XSLT
* AWS (EC2)
